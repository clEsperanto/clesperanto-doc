Filters
-------

List of Tiers classes from the `net.clesperanto.kernels` package.
The Tiers classes hold the different operations that are available in clesperantoJ.
These operations are grouped by their complexity, following the rules that a function in tier N implement a function from tier N-1.
It is mainly an internal organisation to facilitate the development and the maintenance of the library.
Each filter is a static method of its respective Tiers class and can be called directly without instantiating the class.
